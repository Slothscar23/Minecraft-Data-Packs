# Minecraft Data Pack Templates

This repository folder contains a template datapack and an example datapack "Geronimo" that demonstrates a trigger-based function which teleports the player 100 blocks up.

Usage
- To use the Geronimo datapack in-game, run: `/trigger geronimo set 1` (this requires the datapack's `load` function to have run at least once so the objective exists).
- Contributors can copy `packs/template-pack` to create other datapacks.

Files added:
- packs/template-pack/*  — generic template datapack
- packs/geronimo/*      — example datapack with a trigger `geronimo`
